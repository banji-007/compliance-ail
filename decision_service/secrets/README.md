# Vault token (generated, not committed)

`vault_api_token.txt` is generated by `make keygen` (idempotent, same as
`keys/signing.key`) and is gitignored. It is mounted into the
`decision-service` container only, as a Docker Compose secret, and is never
attached to the agent (`langgraph-demo`) container - that separation is the
D14 credential boundary this phase builds. See `docs/adr/0008-decision-service-boundary.md`.

To generate it manually: `openssl rand -hex 32 > decision_service/secrets/vault_api_token.txt`
